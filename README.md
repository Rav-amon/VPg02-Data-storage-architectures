# Хранение данных: Pinecone и телеграм-бот

Учебный проект: фразы и факты лежат в векторном индексе Pinecone, а телеграм-бот перед ответом подмешивает в контекст ближайшие воспоминания.

Индекс `vpg02data-storage` — документный. Текст пишется в поле `chunk_text`, эмбеддинг считает сам Pinecone моделью `llama-text-embed-v2` (1024 измерения, cosine). Готовый вектор OpenAI `text-embedding-3-small` (1536 измерений) этот индекс не принимает.

## Состав

| Файл | Назначение |
|---|---|
| `pine.py` | Клиент Pinecone: подключение, запись, чтение, поиск, удаление |
| `bot.py` | Телеграм-бот с памятью |
| `test.py` | Пример поиска по фразам о египетских пирамидах |
| `requirements.txt` | Зависимости |
| `.env` | Ключи. В репозиторий не класть |

## Подготовка

Нужен Python 3.12. Окружение уже создано в папке `venv`.

```powershell
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

В `.env` должны быть такие переменные:

```env
OPENAI_KEY=ключ ProxyAPI
PINECONE_API_KEY=ключ Pinecone
PINECONE_INDEX=vpg02data-storage
TELEGRAM_BOT_TOKEN=токен из BotFather
```

`OPENAI_KEY` — ключ [ProxyAPI](https://proxyapi.ru), не ключ OpenAI напрямую. Запросы идут на `https://api.proxyapi.ru/openai/v1`. Токен бота выдаёт [@BotFather](https://t.me/BotFather).

## Клиент Pinecone

`PineconeClient` в `pine.py` смотрит схему индекса при `connect()`.

- Документный индекс: запись идёт через documents API. Текст берётся из `metadata["phrase"]` и кладётся в поле с `embed` (`chunk_text`). Пространство имён не может быть пустым.
- Векторный индекс с полем `dense_vector`: запись идёт обычным `upsert` готовых координат.

Методы:

| Метод | Что делает |
|---|---|
| `connect()` | Открывает индекс и читает схему |
| `write()` | Записывает векторы или документы. Тот же `id` перезаписывается |
| `read()` | Читает записи по идентификаторам |
| `search()` | Ищет ближайшие. Для этого индекса передавайте `query_text`, не вектор |
| `delete()` | Удаляет по `id`, по фильтру или всё пространство имён |

Фразы о пирамидах лежат в пространстве имён `phrases`, идентификаторы `"1"` … `"20"`. В консоли Pinecone на экране видна первая страница из 10 записей.

## Поиск из test.py

```powershell
python test.py
```

Скрипт подключается к индексу и печатает результат `search`. Текст запроса задаётся в `query_text`.

## Телеграм-бот

```powershell
python bot.py
```

Перед каждым ответом `SearchVectors` достаёт до 10 ближайших воспоминаний этого чата и передаёт их модели `gpt-4o-mini`. Новый факт сохраняется в пространство имён `memories-<id чата>`.

- Обычное сообщение: модель отвечает и, если в тексте есть полезный факт, сохраняет его.
- `запомни ...`: сохраняется именно эта фраза.
- `/start` и `/help`: короткая справка.

Обрыв вида `Connection aborted` / `Remote end closed connection` приходит от Telegram в момент отправки ответа. Бот при этом не останавливается: сообщение можно отправить ещё раз.
